## About me

- I'm an **SDE 2 at [Falkram](https://www.falkram.com)**. I ship on [Skyll](https://www.skyllai.com), our AI grading product, live with coaching institutes in India: I built and hardened the Android app teachers use to scan answer sheets, the upload pipeline, the pre-launch security fixes and the CI gates.
- I also **build client platforms** at Falkram: backend, access-control and security work on an enterprise SaaS platform and a custom ERP.
- I **write labs developers can finish**. My [IronClaw gitorials](https://github.com/Raj-RR1/ironclaw-calculator-tool-gitorial) take you from an empty Rust crate to a sandboxed WASM tool an AI agent can call, through numbered `TODO`s with a checkpoint at each step, a format I borrowed from [Shawn Tabrizi's](https://github.com/shawntabrizi) [Rust State Machine](https://github.com/shawntabrizi/rust-state-machine) tutorial. The calculator lab has been **forked 14 times** by workshop attendees.
- I've **built AI agents on real chains**. At GRYD, on [Agent Dot](https://github.com/edgeware-network/agent-dot) I wrote the staking and nomination-pool agents, rebuilt the wallet layer, and added batch transactions with a live transaction queue — **8 merged PRs** and two delivered [Polkadot Fast-Grants](https://github.com/Polkadot-Fast-Grants/delivery) milestones.
- I've **done the protocol plumbing**. Earlier at GRYD I moved Edgeware's [Substrate node](https://github.com/edgeware-network/edgeware-node) across Polkadot SDK releases up to `polkadot-v0.9.25` for a forkless runtime upgrade, with SubXT tests checking chain behaviour across it.
- I **teach in person**. Since 2026 I run AI-agent sessions with [ArQ](https://thearqhive.org), NEAR's city node in India. Before that I taught at IIT Bombay (a two-day, **405-attendee** workshop), IIT Roorkee, NITK and ETHIndia, and **mentored 190 hackers** through one hackathon round.

## Selected Projects

### [Carry Trade Vault](https://github.com/Raj-RR1/carry-trade-vault)

A Solidity vault built for the Polkadot Solidity Hackathon 2026 on Polkadot Hub EVM. It explores a cross-chain carry trade using XCM, minting yield-bearing vDOT on Bifrost and hedging exposure on Hydration, with XCM flows composed directly in Solidity.

**Highlights:** Solidity, XCM, Polkadot Hub EVM, Hardhat, React, Vite

### [OmniStrat AI](https://github.com/Raj-RR1/omnistrat-ai)

An AI-powered DeFi strategy assistant that lets users perform swaps, bridging, lending, and cross-chain actions through natural language. It combines LLM tool calling with blockchain execution flows across multiple protocols.

**Highlights:** Next.js, React, TypeScript, Vercel AI SDK, wagmi, viem, LI.FI, Aave, Circle, ENS

### [JudgePass](https://github.com/Raj-RR1/JudgePass)

A verifiable hackathon judging system that packages judging logic into Intelligent NFTs, uses TEE-verified compute for scoring, and stores immutable scorecards on 0G Storage for transparent and auditable evaluation.

**Highlights:** TypeScript, Bun, 0G Storage, 0G Compute, Ethers, INFTs

### `edgeware-node`

A Substrate-based proof-of-stake smart contract blockchain focused on community governance, treasury management, and decentralized proposals. I contributed to Edgeware's testnet runtime and node upgrade work, including the merged [`runtime and node upgrade based on polkadot-v0.9.25`](https://github.com/edgeware-network/edgeware-node/pull/51) pull request for the `prerelease_v4.0.8` line.

**Highlights:** Rust, Substrate, runtime upgrades, node infrastructure, JSON-RPC migration, governance systems

### [agent-dot](https://github.com/edgeware-network/agent-dot)

An AI-powered interaction layer for the Polkadot ecosystem. I worked on `agent-dot`, a project built with a modern Next.js and React stack together with `polkadot-api` to make Polkadot workflows more accessible through a cleaner application interface.

**Highlights:** Next.js, React, TypeScript, Polkadot API, Tailwind CSS
